# Bored - Bored Extension

Block distracting sites and, instead of staring at a wall, spin a wheel to find
something better to do.

## Features

- Throws up a wall when you try to visit a distracting site.
- Offers a list of better sites to jump to instead.
- A suggestion wheel: every click spins through a list of ideas and lands on one
  for you to do next.

## How it works

When a blocked domain loads, the extension replaces the page with a "bored"
interstitial. Pick one of the suggested better sites to redirect to, or spin the
suggestion wheel until it lands on something to do.

## Install

Load as an unpacked extension in Chrome/Edge/Firefox from `dist/v3` (or `dist/v2`).
