# Omni — UI/UX Design — Screen Designs

_Part of [07-ui-ux-design.md](../../07-ui-ux-design.md)._

## Tabs (alphabetical)

Ads, BackToTop, Block, Chess, Claude, GitHub, Insta, New Tab, Shopify, Snap, Sound. Contextual tabs (Chess, Claude, GitHub, Insta, Shopify) start hidden; shown when active tab matches domain.

## Pane details

- **Ads**: Toggle "Block ads" (hide ads and tracking requests). ID `blockAds`.
- **BackToTop**: Toggle show Back to Top button; hint explains behavior.
- **Block**: Toggle "Block distracting sites".
- **Chess** (contextual): Toggle hide ratings & overlays on Chess.com.
- **Claude** (contextual): Daily/weekly usage values and reset times; toggle track usage (badge + indicator). Reads /rate_limits and /usage.
- **GitHub** (contextual): Toggle open external links in new tab.
- **Insta** (contextual): Toggle Shift+right-click to open carousel images.
- **New Tab**: Toggle redirect new tabs + target URL input.
- **Shopify** (contextual): "Check Shopify" button; verdict; Shopify and Shopify Plus indicator lists.
- **Snap**: Two mode buttons (Current View, Full Page), format/quality/autosave controls (PNG/JPEG, quality slider, filename pattern), status line.
- **Sound**: Count of playing tabs; actions (Mute all, Mute others); scrollable list of sound rows with favicon, title, meta, mute toggle. Empty state shown when none playing.
