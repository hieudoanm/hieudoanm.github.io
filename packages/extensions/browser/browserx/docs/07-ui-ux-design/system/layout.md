# Omni — UI/UX Design — Layout

_Part of [07-ui-ux-design.md](../../07-ui-ux-design.md)._

## Structure

- `.header` with brand name ("omni") and tag; tab info line (`#tabUrl`).
- `.tabbar` horizontal tabs (scrollable in overflow cases; compact fixed width popup).
- `.body` container with `.pane` sections (only active visible).
- Fixed width: ~320-360px depending on prototype/view. Dark theme background.
