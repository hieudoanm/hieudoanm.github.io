# Ads Blocker

Blocks ads, banners, and tracking requests across every web page — without
sending any data anywhere.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — tech stack, build pipeline, MV2/MV3 strategy

- [docs/PACKAGING.md](docs/PACKAGING.md) — packaging and store-submission checklist
- [docs/DOWNLOADS.md](docs/DOWNLOADS.md) — download links per browser

## Install

Load as an unpacked extension in Chrome/Edge/Firefox from `dist/v3` (or `dist/v2`).
