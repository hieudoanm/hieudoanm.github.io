Overview

A lightweight ad blocker that works at two layers: the browser cancels requests to known ad and tracking domains before they load, and a content script hides ad containers and banners that slip through.

MV3 Network blocking

Native declarativeNetRequest rules block doubleclick, Google Analytics, Google Syndication, AdNxs, Outbrain, and Taboola — the browser does the work, so no JavaScript runs on the request path.

MV2 Network blocking

Identical domain list, enforced with a blocking webRequest listener for Firefox and legacy Chromium builds.

DOM hiding

Hides ad containers, banners, and placeholders with safe attribute selectors and display: none !important, plus a MutationObserver that catches ads injected after the page loads.

Private by design

100% offline and stateless. No remote block lists, no analytics, no metrics — no user data collected, transmitted, or stored.
