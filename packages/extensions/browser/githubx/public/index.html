Overview

Stays on github.com by routing every external link into a new tab — your repo, PR, or issue page never navigates away.

One listener

A single delegated document click listener handles every link on the page — no per-link bindings, no re-registration.

Smart resolution

Resolves protocol-relative, root-relative, and relative hrefs against github.com before deciding what's external.

Stays on GitHub

External links open via window.open(url, '_blank'); internal links, #anchors, and javascript: URIs are ignored.

Zero footprint

Runs at document_idle on *.github.com only — no storage, no network calls, nothing to sync.
