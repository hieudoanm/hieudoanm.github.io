## Project title

A computational model of memory formation and removal

## Project summary

Working memory describes the ability to maintain information that is no longer present in the environment. It provides a flexible mental workspace that scaffolds most higher cognitive functions. For a long time, a central objective in neuroscience has been to understand brain mechanisms that underpin working memory. This research has made great progress in revealing how the brain retains information, but it has neglected a key aspect: how are memories removed when they are no longer relevant for guiding behaviour?

Understanding removal mechanisms is important. Working memory only has a very small capacity, so efficient removal is critical to make optimal use of this mental workspace. Conversely, several mental health conditions are characterised by difficulties with removal (e.g., rumination in depression or intrusive thoughts in OCD), so understanding mechanisms behind removal may also inform better treatment to advance mental health.

This project will leverage computational modelling to interrogate how the human brain dynamically forms and dissolves memories for adaptive behaviour in a rapidly changing world.

## Methodology

This project will interrogate how the human brain adaptively removes memories. It will extend an existing computational model that provides an excellent fit to diverse brain recording data during memory maintenance (Manohar et al, 2019 – see seed references). We will equip the model with different removal mechanisms (implemented via spiking activity or synaptic plasticity), and examine its dynamics under different task demands. Careful simulations will be conducted to generate diagnostic experimental predictions to probe the contribution of each mechanism to memory removal in the human brain.

Working on the project will involve reading relevant literature, conducting simulations (under close supervision), and contributing to the interpretation of results. Depending on the student’s interest, the project may also involve testing some of the newly generated predictions via targeted behavioural experiments. The project will be carried out in close collaboration with Prof Sanjay Manohar at the University of Oxford.
