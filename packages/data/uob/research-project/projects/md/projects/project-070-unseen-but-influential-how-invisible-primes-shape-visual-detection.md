## Project title

Unseen but Influential: How Invisible Primes Shape Visual Detection

## Project summary

This project will test a very simple hypothesis – that invisibly presenting stimuli will prime subjects to be better able to detect those stimuli. We will use a form of rapid invisible stimulus presentation to invisibly prime participants and observe how thee primes then affect behavior. We will do this first with a series of simple visual search and detection tasks.
