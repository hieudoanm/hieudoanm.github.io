## Project title

Using eye-tracking to understand the role of attention in decision-making

## Project summary

The project aims to understand how attentional processes drive decision-making. The project will use the eye-tracking lab to collect data on participants performing a decision-making task (for instance, splitting a monetary amount with another person or playing a simple risk or strategic game). The project will use visual displays to manipulate attention and measure gaze patterns to understand how these manipulations affect choices.
