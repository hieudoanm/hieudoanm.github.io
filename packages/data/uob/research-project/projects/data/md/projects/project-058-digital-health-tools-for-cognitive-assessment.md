# Digital health tools for cognitive assessment

## Project ID

Project 58- Andrew Olson- 84- "Digital health tools for cognitive a..."

## Project title

Digital health tools for cognitive assessment

## Project summary

We are developing digital tools for cognitive assessment of children with neurodegenerative disorders in order to track cognitive changes accurately without requiring families to attend frequent disruptive visits to clinic.  We will develop and/or test tools for assessment of gait, fine motor control, memory or language.  The exact target can be discussed early on.  Testing will be on controls (not children) to establish reliability and validity and to gauge useability for home testing.

## Topic

cognitive assessment, gait, fine motor control, memory, language, childhood neurodegenerative disease

## Methodology

Reliability and validity testing of digital apps
