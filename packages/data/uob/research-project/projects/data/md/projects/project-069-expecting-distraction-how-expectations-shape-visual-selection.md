## Project title

Expecting Distraction: How Expectations Shape Visual Selection

## Project summary

This project will seek to understand how expectation changes how people deal with distractions during visual search tasks. Participants will perform a simple visual detection task where they will need to identify a unique shape in a shape array. Importantly they will be told that there is either a high or low chance of distractors appearing in this experiment block. We will use signal detection theory to observe how these expectations affect their ability to detect targets under these different expectations.
