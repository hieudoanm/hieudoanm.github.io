# Make Virtual Objects Feel Real: Can Simple Vibrations Create Convincing Material Illusions?

## Project ID

Project 29- Massimiliano Di Luca- 61- "Make Virtual Objects Feel Real: Can ..."

## Project title

Make Virtual Objects Feel Real: Can Simple Vibrations Create Convincing Material Illusions?

## Project summary

Virtual reality can create convincing visual worlds, but virtual objects often feel insubstantial because users receive little information through touch. This project will investigate whether simple vibrations can make virtual materials feel more realistic and easier to distinguish. Participants will interact with virtual objects representing contrasting material properties, such as softness, hardness or roughness. Contact with each object will produce carefully designed vibrations through a standard VR controller or another readily available haptic device. The experiment will compare feedback that is congruent with the displayed material, incongruent feedback and visual information without informative vibration. The project will test whether appropriately designed vibration improves material identification, perceived realism, confidence and interaction performance. It will also examine whether conflicting visual and tactile information changes which material participants believe they have encountered. This project connects fundamental research on multisensory perception with applications in immersive gaming, remote interaction, training and accessible technology. Existing equipment and starter software will be provided, and no previous VR programming experience is required. The study may contribute to a preregistered open dataset and a subsequent publication.

## Topic

Haptic perception; virtual reality; vibrotactile feedback; multisensory integration; material perception; tactile illusions; psychophysics; immersive technology

## Methodology

Quantitative within-participant VR experiment. Participants will compare virtual materials under congruent-vibration, incongruent-vibration and visual-only conditions. The core project will examine one material dimension and a small, controlled set of vibration patterns. Primary outcomes will be material-identification accuracy and perceived realism. Secondary outcomes may include confidence, response time, preference and task performance. Sample size will be determined by an a priori power analysis. Repeated-measures or mixed-effects models will test whether feedback condition affects perception and performance. An optional psychometric or computational-modelling extension will be available for students with appropriate experience. The study will be preregistered and scoped so practical work can be completed by May.
