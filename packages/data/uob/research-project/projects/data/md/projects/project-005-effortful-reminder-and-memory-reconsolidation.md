## Project title

Effortful reminder and memory reconsolidation

## Project summary

Reminder of previously-learned information can engage a process of memory destabilisation-reconsolidation. However, the rules around the nature of memory reminder that makes it effective at destabilising memory are not well understood. Across various studies, these "boundary conditions" on memory reconsolidation have been described and related to processes such as prediction error or mismatch between expectations and outcomes. Another interpretation is the level of effort engaged in the reminder, which intersects with the engagement of additional learning or memory updating. This project will aim to disambiguate retrieval effort from prediction error or mismatch. It can do this either in established learning paradigms (e.g. list of visual images), or integrate additional novelty by changing the learning material (e.g. list of facial images).
