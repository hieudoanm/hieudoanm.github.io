## Project summary

Co-registration is the process of aligning data from different sources into a single coordinate system. In MEG (magnetoencephalography), this involves aligning sensor positions with anatomical images from MRI scans to ensure that brain activity is accurately mapped to the participant’s brain surface. Optically Pumped Magnetometers (OPMs) offer a modern, flexible alternative to traditional MEG systems. Our OPM-MEG system uses an array of sensors embedded in a smart helmet, which adjusts to the participant's head shape and automatically tracks sensor positions.
Traditionally, co-registration relies on digitizing head shapes using tools like the Polhemus tracker and aligning sensor positions with MRI data through anatomical landmarks. However, new technologies, such as smart helmets and smartphone-based 3D scanning apps, provide alternative methods for co-registration.
Recently, we have developed a dedicated co-registration graphical user interface (GUI) that facilitates the use of 3D head scans for OPM-MEG co-registration. This project offers an opportunity to help shape the next stages of this development and explore future directions for improving co-registration workflows. Depending on your interests and skill set, possible project directions include testing and validating the GUI using existing OPM-MEG datasets, learning about source reconstruction methods, and comparing the performance of different co-registration approaches based on Polhemus digitization, smart helmet sensor localization, and 3D scan-derived head surfaces. There may also be opportunities to assist with pilot OPM-MEG data collections and apply these methods to newly acquired datasets. Alternatively, students with strong Python programming skills and experience working with GitHub-managed projects can contribute directly to the ongoing development of the GUI by implementing new features and improving its functionality. Through these activities, the project will contribute to advancing practical, accurate, and user-friendly co-registration solutions for OPM-MEG research.
