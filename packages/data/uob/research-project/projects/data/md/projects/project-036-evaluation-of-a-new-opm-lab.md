## Project title

Evaluation of a new OPM lab

## Project summary

The Centre for Human Brain Health is finalising the construction of a new OPM facility that will start to collect its first data in 2026/27. This project is an opportunity to assist with the initial validation of the lab setup. We will work with technical pilot data from the new OPM facility to establish critical information about how the system is running. We will characterise factors such as the level of background noise in the lab, the efficacy of the shielded room and the best operating modes for the sensors. We will explore both simulated artefacts and real potential sources magnetic noise alongside methods for removing them. We will create important resources such as maps of magnetic interference within the room and optimal operating conditions for testing.

There will be possibility to apply these technical analysis to some of the first human data to be acquired on the system. There will be some opportunities to gain some experience with the lab itself. This is a rare opportunity to contribute to a very exciting time at the CHBH and the work performed here can be important for establishing how we use the lab going forward.

Please get in touch with any questions, this is an unusual project!
