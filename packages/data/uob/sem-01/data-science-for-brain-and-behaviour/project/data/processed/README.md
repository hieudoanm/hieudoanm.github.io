# Processed and derived data

`enni_inventory.csv` is generated by `scripts/audit_enni.py`. It records transcript metadata and annotation-marker counts while leaving every `.cha` source untouched.

`mlcu_provisional.csv` is generated by `scripts/analyse_enni.py`. It is an automated approximation based on CHAT main tiers, existing `[+ bch]` tags, selected break-off codes, and heuristic maze/filler removal. Treat scores as provisional pending review of the official MLCU exclusions.

`mlcu_question_sensitivity.csv` is a rough sensitivity case that additionally removes each child turn immediately following an examiner question. This broad rule may over-exclude and is not a recommended final score without transcript review.

`mlcu_scoring_template.csv` is a 360-participant manual review sheet if the group decides to replace or correct candidate scores. Do not regenerate it after entering review scores.

Regenerate the inventory with `python3 scripts/audit_enni.py` and candidate scores with `python3 scripts/analyse_enni.py`. The manual template is initialized from the inventory and should not be regenerated after entering review scores.
