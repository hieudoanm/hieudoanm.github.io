# Task 010: CLI

## Feature

### Status

completed

### Goal

Implement command-line interface for the browser.

### Requirements

- Load HTML from file
- Headless mode
- Screenshot output
- Viewport configuration
- Dump DOM tree

### Non-goals

- Network URL loading
- GUI mode
- PDF output
- Developer tools

### Implementation

- `clap`-based CLI with derive API
- `--headless` flag
- `--screenshot` flag
- `--width` and `--height` for viewport
- `--dump-dom` for DOM tree output

### Verification

- Binary compiles
- `cargo build -p cli`

### Acceptance Criteria

- Can load HTML file
- Can take screenshot
- Can set viewport size
- Can dump DOM tree
- Proper error handling

### Notes

- Network fetching not implemented yet
- GUI mode not implemented yet
