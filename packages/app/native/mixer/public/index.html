Overview

A menu-bar audio mixer for the default output device, with running apps listed and ready for per-app volume control.

System volume

A slider and mute toggle control the default output device from the menu bar.

Current device

The active output device is shown right in the app so you always know what you're adjusting.

Running apps

Apps that are currently playing are listed with their icons and per-app volume rows.

Guarded control

An accessibility permission screen gates access until you explicitly allow it.
