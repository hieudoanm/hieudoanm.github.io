## About

Mixer — per-app volume control for macOS.

## Features

## Menu Bar

- Menu bar icon with speaker symbol
- Popover UI for quick access
- System volume slider with percentage display
- Mute/unmute toggle button

## Application Discovery

- Detects running applications with visible windows
- Shows all regular (non-background) apps
- Displays app icons and names
- Sorted alphabetically

## Volume Control

- System-wide volume slider
- Real-time volume adjustment
- Volume percentage display (0-100%)
- Mute/unmute for system audio

## Settings

- Launch at login preference
- Show inactive apps toggle
- Remember volumes toggle
- Global shortcut configuration

## UX

- Lightweight menu bar utility
- No dock icon (accessory mode)
- Fast startup
- Low memory footprint
- Local-first, no network dependency

## Requirements

- macOS 13+
