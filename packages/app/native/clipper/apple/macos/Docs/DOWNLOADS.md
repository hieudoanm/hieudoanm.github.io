## About

Clipper — native macOS clipboard manager.

## Features

## Menu Bar

- Menu bar icon with clipboard symbol
- Popover UI for quick access
- Clipboard history list
- Search through history

## Clipboard Management

- Automatic clipboard monitoring
- Text, image, and file support
- Clipboard history with timestamps
- Deduplication of repeated copies
- Pin important items

## Search & Filtering

- Search through clipboard history
- Filter by content type
- Quick copy with one click

## Settings

- Maximum history items
- Launch at login preference
- Global shortcut configuration

## UX

- Lightweight menu bar utility
- No dock icon (accessory mode)
- Fast startup
- Low memory footprint
- Local-first, no network dependency

## Requirements

- macOS 13+
