Overview

A menu-bar clipboard manager that keeps every copy — text, image, or file — so you can find anything you copied and paste it back with one click.

Grabs everything

Text, images, and files from the pasteboard are captured automatically, every half second.

Search & filter

Search or filter history by type, and pin favorites so they're always one click away.

One-click re-copy

Any entry can be copied straight back to the pasteboard straight from the menu bar.

History you control

Toggle monitoring on or off and set the history size from 100 to 5,000 entries.
