# Features

> Snap — snap your workspace. Restore it anytime.

## Window Snapping

- Snap windows to predefined zones
- Left/right/top/bottom halves
- Quarter positions (top-left, top-right, bottom-left, bottom-right)
- Maximize and center
- Keyboard-driven snapping

## Workspace Management

- Save current window arrangement as named workspace
- Restore saved workspace with one click
- List all saved workspaces
- Edit workspace names and windows

## Multi-Monitor

- Detect multiple displays
- Associate windows with specific monitors
- Adapt layouts to different resolutions
- Handle monitor connect/disconnect

## Application Matching

- Match windows by bundle identifier
- Tolerate changing window titles
- Support multiple windows per app
- Track window ordering

## Menu Bar

- Menu bar icon with grid symbol
- Popover UI for quick access
- Saved workspaces list
- Save current layout option

## Settings

- Launch at login preference
- Global shortcut configuration
- Missing app behavior (ignore/ask/launch)

## UX

- Lightweight menu bar utility
- No dock icon (accessory mode)
- Fast startup
- Low memory footprint
- Local-first, no network dependency
