## About

Top -- always-on-top for any window, from your menu bar.

## Features

## Menu Bar

- Pin.fill icon in the menu bar
- Click to open popover with all open windows
- Windows grouped by application
- App icons displayed next to each window

## Window Pinning

- One-click toggle to pin/unpin any window
- Pinned windows always stay on top (level 25)
- Visual indicator for pinned windows (checkmark badge)
- Unpin button on each pinned window

## Persistence

- Pinned windows saved to `~/Library/Application Support/Top/pinned_windows.json`
- Pinned windows restored on app launch
- Re-pin windows automatically when apps relaunch (optional)

## Settings

- Launch at login toggle
- Re-pin on app launch toggle
- Clear all pinned windows
- Request accessibility permission

## UX

- Popover-based UI anchored to menu bar
- Permission prompt on first launch if Accessibility not granted
- Auto-refresh window list every 2 seconds
- Empty state when no windows are open

## Requirements

- macOS 13 Ventura
