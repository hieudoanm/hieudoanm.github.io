# Roadmap

## Phase 1 — Portal Core

> Foundation: app hub, routing, theming

- [x] Start / home page
- [x] Apps portal with category index
- [x] Settings and version pages
- [x] Dark theme default (DaisyUI)
- [x] Static export + PWA manifest
- [x] Responsive layout (web, desktop, mobile)
- [ ] Download manager with asset tracking
- [ ] Resume page with print/export

## Phase 2 — App Categories

> Growth: fill out each category with useful tools

- [x] Utilities: clipboard, colors, lorem ipsum, emojis
- [x] Developer: UUID, IP, text diff, URL tracer
- [x] Text convert: Morse, braille, leet speak, text case
- [x] Calculators: tax, inflation, split bill
- [x] Clocks: pomodoro, countdown, cron, epoch convert
- [x] Psychology: BDI, GAD-7, Big Five, relationship scales
- [ ] Data tools: CSV/JSON/XML converters, merge and diff
- [ ] Editors: markdown, JSON, and code editing tools
- [ ] Visualization: chart and graph generators

## Phase 3 — Advanced Apps

> Power: games, media, ML-powered tools

- [x] Chess game with audio feedback
- [ ] Screen recorder and media utilities
- [ ] Screen-capture annotation tool
- [ ] Invoice parser (ONNX + web worker)
- [ ] Signature model (ONNX) integration
- [ ] PDF tools via web worker
- [ ] NoSleep and productivity helpers

## Phase 4 — Platform & Integration

> Ecosystem: native builds, sync, expansion

- [ ] Tauri desktop app build and signing
- [ ] iOS/Android native shells (Tauri Mobile)
- [ ] User accounts and cross-device sync (mock)
- [ ] Third-party API integrations (weather, currency)
- [ ] Widget system for the home page
- [ ] Installable individual apps from the portal
- [ ] Analytics and usage insights (local-first)
