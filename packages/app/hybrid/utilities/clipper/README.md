# Clipper

A minimal clipboard manager for macOS built with Tauri 2, Next.js 16, and
SQLite.

## Features

- Clipboard history tracking
- Search through history
- Pin important items
- Text and image support
- Dark theme

## Tech Stack

- **Frontend**: Next.js 16, React 19, Tailwind CSS 4, DaisyUI 5
- **Backend**: Tauri 2, Rust
- **Storage**: SQLite
- **Clipboard**: arboard

## Development

```bash
pnpm install
pnpm dev
pnpm tauri dev
```
