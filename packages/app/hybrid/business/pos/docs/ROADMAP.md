# Roadmap

## Phase 1 — Core

> Foundation: item catalog, cart, basic checkout

- [x] Item catalog with name, price, and category
- [x] Cart management (add, remove, update quantities)
- [x] Subtotal and total calculation
- [x] Basic cash payment workflow
- [x] Receipt display after transaction

## Phase 2 — Enhanced

> Polish: tax, receipt printing, transaction history

- [x] Tax calculation (configurable tax rate)
- [x] Digital receipt generation
- [x] Transaction history with search
- [x] Daily sales summary
- [x] Void transaction support

## Phase 3 — Inventory

> Scale: stock tracking, alerts, bulk operations

- [x] Stock level tracking per item
- [x] Low stock alerts
- [x] Inventory adjustment with audit trail
- [ ] Bulk item import/export (CSV)

## Phase 4 — Reporting

> Analytics: sales reports, exports

- [x] Daily/weekly/monthly sales reports
- [x] Top-selling items and categories
- [x] Payment method breakdown
- [x] Tax summary reports
- [x] CSV export for reports

## Phase 5 — Advanced Payments

> Payments: card support, split payments

- [x] Card payment support (integration pending)
- [x] Split payment (cash + card)
- [x] Discount and coupon support
- [x] Gift card support

## Phase 6 — Multi-user & Permissions

> Team: roles, registers, shifts

- [x] User accounts with roles (admin, cashier, manager)
- [x] Cash register management
- [x] Shift tracking (open/close register)
- [x] Permission-based access control

## Phase 7 — Platform & UX

> Polish: themes, offline, mobile optimization

- [ ] Light and dark themes
- [ ] Offline-first with sync
- [ ] Mobile-optimized touch interface
- [ ] Keyboard shortcuts for operations
- [ ] Thermal printer integration
