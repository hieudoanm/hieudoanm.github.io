# Roadmap

## Phase 1 — Core

> Foundation: item catalog, cart, basic checkout

- [ ] Item catalog with name, price, and category
- [ ] Cart management (add, remove, update quantities)
- [ ] Subtotal and total calculation
- [ ] Basic cash payment workflow
- [ ] Receipt display after transaction

## Phase 2 — Enhanced

> Polish: tax, receipt printing, transaction history

- [ ] Tax calculation (configurable tax rate)
- [ ] Digital receipt generation
- [ ] Transaction history with search
- [ ] Daily sales summary
- [ ] Void transaction support

## Phase 3 — Inventory

> Scale: stock tracking, alerts, bulk operations

- [ ] Stock level tracking per item
- [ ] Low stock alerts
- [ ] Inventory adjustment with audit trail
- [ ] Bulk item import/export (CSV)

## Phase 4 — Reporting

> Analytics: sales reports, exports

- [ ] Daily/weekly/monthly sales reports
- [ ] Top-selling items and categories
- [ ] Payment method breakdown
- [ ] Tax summary reports
- [ ] CSV export for reports

## Phase 5 — Advanced Payments

> Payments: card support, split payments

- [ ] Card payment support (integration pending)
- [ ] Split payment (cash + card)
- [ ] Discount and coupon support
- [ ] Gift card support

## Phase 6 — Multi-user & Permissions

> Team: roles, registers, shifts

- [ ] User accounts with roles (admin, cashier, manager)
- [ ] Cash register management
- [ ] Shift tracking (open/close register)
- [ ] Permission-based access control

## Phase 7 — Platform & UX

> Polish: themes, offline, mobile optimization

- [ ] Light and dark themes
- [ ] Offline-first with sync
- [ ] Mobile-optimized touch interface
- [ ] Keyboard shortcuts for快速 operations
- [ ] Thermal printer integration
