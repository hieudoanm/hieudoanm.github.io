# Features

> Keynotes — an offline-first, in-browser presentation tool modeled on
> PowerPoint, Google Slides, and Apple Keynote. Mock in-browser engine, no
> server required.

## Editor

1. Deck management (create, rename, duplicate, delete, thumbnail list)
2. Slide management (add, delete, duplicate, reorder via drag-and-drop)
3. Slide layouts (title, title + content, two content, section header, blank)
4. WYSIWYG canvas (text boxes, shapes, lines, connectors, callouts)
5. Rich text editing (bold, italic, underline, lists, highlight)
6. Multi-select (shift-click, marquee/lasso)
7. Undo / redo
8. Autosave to IndexedDB (offline-first)
9. Zoom (fit, fill, percentage, Ctrl+scroll at cursor) and pan
10. Rulers, guides, gridlines, snap-to-grid, smart alignment guides
11. Page setup (16:9, 4:3, custom; portrait/landscape)

## Formatting

1. Fill styles (solid, gradient, image, pattern, transparency)
2. Outline/stroke (color, width, dash, arrowheads)
3. Effects (shadow, reflection, glow, soft edges, 3D bevel)
4. Quick style presets and format paintbrush
5. Themes (color scheme, font scheme, background, variants)
6. Color tools (eyedropper, hex/RGB, palettes)
7. Font controls (family, size, weight, letter-spacing, line-height)
8. Text effects (WordArt fills/outline, transform/curved text)
9. Arrange (z-order), align, distribute
10. Rotate (free, 90°, exact angle) and flip (horizontal/vertical)
11. Group / ungroup / regroup
12. Position & size panel (x/y/w/h, rotation, aspect-lock)

## Content

1. Images (upload, drag-drop, paste, URL; crop, filters, rounded corners)
2. Media (video/audio embed, play/pause controls)
3. Charts (bar, column, line, area, pie, doughnut, scatter)
4. Tables (merge cells, add/remove rows & columns, styles, borders)
5. SmartArt-style diagram builder (process, cycle, org chart, pyramid, matrix)
6. Icons library (searchable, colorable)
7. Equation editor (LaTeX-style formulas)
8. Freehand drawing / ink (pen, highlighter, eraser)
9. Hyperlinks (slide, URL, email)
10. Embeds (YouTube, Mermaid diagrams, highlighted code snippets)

## Animation & Transitions

1. Entrance / emphasis / exit animations (fade, fly, zoom, bounce, spin, pulse)
2. Motion paths (preset + custom drawn)
3. Triggers (on click, with previous, after previous, on hover)
4. Timing (duration, delay, repeat, reverse, easing)
5. Animation pane (reorder, remove, preview)
6. Text/object stagger
7. Slide transitions (fade, push, wipe, cover, reveal, zoom, split, flip, cube,
   doors, morph)
8. Morph transition between slides
9. Auto-advance timings

## Slide System

1. Slide master with editable placeholders
2. Layout library and template gallery (starter decks)
3. Custom slide sizes and per-slide backgrounds
4. Header & footer (slide numbers, date, logo watermark)
5. Speaker notes (Markdown supported)
6. Thumbnail overview, outline/text view
7. Sections (grouping, naming, reordering)
8. Duplicate / hide slides, reuse slides from other decks

## Presentation

1. Fullscreen presentation mode (keyboard/click navigation)
2. Presenter view (current + next slide, notes, timer)
3. Timer and rehearsal mode with per-slide feedback
4. Live annotations (laser, pen, highlighter, eraser)
5. Blackout / whiteout, spotlight zoom
6. Q&A (audience questions via web, mock)
7. Live captions / subtitles (Web Speech API)

## Import / Export

1. Native JSON project files (save/load)
2. Export PPTX (mock), PDF, PNG/SVG, HTML presentation
3. Import PPTX (mock), Google Slides link (mock)
4. Handouts (multiple slides per page)
5. Theme/template export

## Collaboration

1. Realtime multiplayer (mock: BroadcastChannel across tabs)
2. Presence (avatars, cursor highlights)
3. Threaded comments (resolve, @mentions)
4. Version history (snapshots, restore, diff)
5. Sharing links with view/comment/edit roles
6. Review mode with accept/reject (mock)

## Platform

1. Tauri desktop build
2. PWA / offline support (service worker)
3. Full keyboard shortcuts
4. Accessibility (ARIA, focus management, keyboard-only editing)
5. Responsive layout (tablet editing, mobile viewing)
6. Dark / light themes
7. Skeleton loading states and page transitions
