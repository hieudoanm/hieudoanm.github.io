# Roadmap

> Phased roadmap. Shipped items live in `docs/FEATURES.md`.

## Phase 1 — Foundation (shipped)

- [x] Scaffold from lingo conventions, modernised deps
- [x] Custom light/dark themes with FOUC-free bootstrap
- [x] Home hub + ToolTemplate navigation
- [x] CI workflow wired to repo release pipeline

## Phase 2 — Core tools (shipped)

- [x] Through the Years: core engine, timeline, card placement, scoring
- [x] 4 game modes (Practice, Classic, Endless, Hardcore)
- [x] 15 deck options with continent grouping
- [x] Browse mode (compact + spread views, compare decks)
- [x] Hint system (century, decade, neighbour reveal)
- [x] Combo and speed bonus scoring

## Phase 3 — Learning experience

- [ ] Daily challenge mode (seed from UTC date)
- [ ] Blitz mode (60-second timed)
- [ ] Zen mode (no timer, relaxed)
- [ ] Achievement system (first win, streaks, perfect game)
- [ ] Search events by title, year, category
- [ ] Statistics tracking (games played, accuracy, favourite category)

## Phase 4 — Platform

- [ ] Mobile stores distribution (Play Store / App Store)
- [ ] Offline support with PWA
- [ ] Additional decks (Japan, Korea, Brazil, Australia)
- [ ] Multiplayer mode (same events, fastest correct wins)
- [ ] Leaderboards (daily, weekly, all-time)
