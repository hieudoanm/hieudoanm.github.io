# Roadmap

## Phase 1 — Core Color Tools

> Foundation: parsing, conversions, and basic utilities

- [x] Color converter (HEX, RGB, HSL, HSV, CMYK)
- [x] Color adjuster (hue, saturation, lightness sliders)
- [x] Color wheel with harmonic relationships
- [x] Color schemes (complementary, analogous, triadic)
- [x] Contrast checker (WCAG AA/AAA)
- [x] Shades and tints scale generator
- [x] Tint, shade and tone step builder
- [x] Color mixer with weight control
- [x] Color temperature classifier and Kelvin mapping
- [x] Gradient builder (linear and radial CSS)
- [x] Opacity overlay preview
- [x] Color blindness simulation (protanopia, deuteranopia, tritanopia)
- [x] CSS scale exporter (custom properties)
- [x] Palette generator (random harmonious palettes)
- [x] Random color generator with lock
- [x] Theme colors browser
- [x] 16 tool components, one per page

## Phase 2 — Enhanced UX

> Polish: theming, accessibility, offline support

- [x] Dark and light theme toggle (DaisyUI v5)
- [x] Service worker registration (PWA)
- [x] Copy-to-clipboard on color values
- [x] Responsive layout (mobile, tablet, desktop)
- [ ] Keyboard shortcuts across tools
- [ ] Undo/redo for adjustment sliders
- [ ] Before/after comparison for adjustments
- [ ] Favorite/bookmark colors for quick access
- [ ] History of recently used colors
- [ ] Color name lookup (CSS named colors)
- [ ] Export palette as image or PDF

## Phase 3 — Advanced Features

> Power: batch operations, custom scales, integration

- [ ] Custom color scale builder (user-defined stops)
- [ ] Batch convert multiple colors at once
- [ ] Import/export color palettes (ASE, CLR, JSON)
- [ ] Accessibility report for entire palette
- [ ] Color token generator for design systems
- [ ] Plugin system for custom color tools

## Phase 4 — Platform & Distribution

> Native: desktop builds, mobile shells, store distribution

- [x] Tauri desktop app build (bundling configured; signing not yet)
- [ ] macOS notarization and code signing
- [ ] Windows code signing
- [ ] Auto-update pipeline (Tauri updater plugin)
- [ ] iOS/Android native shells (Capacitor or Tauri Mobile)
- [ ] App Store and Play Store listings
