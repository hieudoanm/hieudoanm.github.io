## Gameplay

A 10-round true/false quiz. Each round shows a popular claim and the player
judges whether it is a myth or an actual fact (`M`/`F` keys). The reveal states
the real truth, tracks score and streak, and the results screen breaks down
accuracy per category. `R` resets, `Esc` closes.

## Data

`items.csv` is the single source of truth with columns
`category,myth,fact,true`. After editing it, regenerate the JSON:

```bash
ts-node --project scripts/tsconfig.json \
  src/components/routes/games/trivia/MythVersusFact/data/scripts/convert-csv-to-json.ts
```

- `category` — topic group shown on the card and used in the results breakdown
- `myth` — the claim presented to the player
- `fact` — the truth revealed after guessing
- `true` — `y`/`n`: whether the `myth` claim is actually a fact (trick items
  where the popular belief is correct)

## Logic

- `shuffle` — Fisher-Yates reorder without mutating input
- `buildDeck` — shuffled slice of `ROUNDS` items
- `correctGuess` — `fact` when the claim is true, else `myth`
- `isCorrectGuess` — compares the player's guess to the correct answer
- `gameReducer` handles `GUESS` (score/streak/results), `NEXT` (end at deck
  end), and `RESET`, driving phases `playing → reveal → done`

## Coding Rules

1. Arrow functions only — no `function` keyword
2. Explicit types on all exports — never `any`
3. Game logic MUST be pure functions in `utils.ts` — zero UI imports
4. State management: Zustand for complex games, `useState`/`useReducer` for
   simple ones
5. TailwindCSS v4 + DaisyUI v5 — no CSS modules, no styled-components
6. Icons: `react-icons/pi` (Phosphor)
7. Each game component receives `onClose: () => void` prop
8. Keep files under 200 lines, functions under 30 lines
9. Test behaviour, not implementation — Jest + Testing Library
10. Mobile-first responsive design
11. `GAME_SECTIONS` consumes `data/games.json` — never hardcode game sections in
    components
