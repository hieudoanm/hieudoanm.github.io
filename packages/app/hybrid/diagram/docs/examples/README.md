# Example Diagrams

A set of system-design interview examples ships with the app. Open them from the
**Examples** button in the toolbar and use the search box to filter, or copy the
sources below. Each example lists a few classic interview questions it was
designed to illustrate.

Examples are defined in `src/lib/examples.ts`. Add a new entry there (unique
`id`, `name`, `description`, `questions`, and a `text` source that parses
cleanly) and it appears in the toolbar automatically.
