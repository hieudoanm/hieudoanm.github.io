# dbml (Go) — FEATURE-02: SQL Generation

Renders the parsed AST as PostgreSQL-compatible DDL. Priority: **P0** (core platform, [`02-features.md`](../02-features.md) §2). dbml is a software demonstration, not a full database modeling tool.

## 1. User-visible behaviour

- `dbml sql schema.dbml` writes a `.sql` file containing `CREATE TABLE` statements for every table, followed by `ALTER TABLE ... ADD CONSTRAINT ... FOREIGN KEY ...` statements for every parsed reference.
- Column types are mapped to PostgreSQL types (`integer` → `INTEGER`, `varchar` → `VARCHAR(255)`, `serial` → `SERIAL`, `timestamptz` → `TIMESTAMPTZ`, `jsonb` → `JSONB`, and so on); types not in the map are uppercased unchanged.
- Column constraints render inline: `PRIMARY KEY`, `UNIQUE`, `NOT NULL`, and `DEFAULT <value>`; string-like defaults are single-quoted if they are not already quoted.
- Unique indexes declared in a table become table-level `UNIQUE (...)` constraints inside the `CREATE TABLE`.
- The file starts with a `-- Generated by dbml CLI` header, and output order follows the source: tables first, then references.

## 2. Inputs

| Input | Provided by |
| ----- | ----------- |
| `*Project` AST | FEATURE-01 parser |
| DBML file (default `schema.dbml`) | `dbml sql [input.dbml]` |
| Output path (`-o`, default `initial_schema.sql`) | `dbml sql` flag |
| Same AST, output directory (`-d`, default `.`) | `dbml all` flag |
| HTTP convert endpoints with `formats` containing `sql` | FEATURE-06 |
| MCP tool `dbml_sql` | FEATURE-07 |

## 3. Outputs

- SQL text as described by [`05-data-model.md`](../05-data-model.md) §4 (`.sql`), written with mode `0644`.
- CLI success line on stdout: `Generated SQL schema: <path>` (or `Generated SQL schema: <dir>/initial_schema.sql` for `all`).
- HTTP/MCP transports return the same text in their response payloads — generation itself writes nothing.

## 4. States

`idle → parsing → generated → complete`; any failure moves to `error` ([`05-data-model.md`](../05-data-model.md) §5). Parse failures stop the run before generation; write failures surface as `write output: ...` / `write SQL: ...` errors on stderr (FEATURE-08).

## 5. Edge cases

- **Enums** — parsed `Enum` blocks are not emitted as `CREATE TYPE` statements; enums appear only in SVG output today.
- **Enum or custom column types** — a column typed with an enum or unknown name is uppercased verbatim and may not be a valid PostgreSQL type without manual adjustment.
- **`unique` on a primary key** — the redundant `UNIQUE` constraint is suppressed when the column is already `PRIMARY KEY`.
- **Non-unique indexes** — retained in the AST but not rendered; only unique indexes produce SQL (`UNIQUE (...)`).
- **Column-level `ref:` settings** — not rendered; foreign keys come exclusively from top-level `Ref:` lines (FEATURE-01 edge cases).
- **Reference direction** — `>` yields `ALTER TABLE <left> ... REFERENCES <right>(...)`; `<` yields `ALTER TABLE <right> ... REFERENCES <left>(...)`.
- **Empty schema** — an AST with no tables and no references produces just the `-- Generated by dbml CLI` header.
- **Unquoted defaults on numeric types** — quoting applies only to types containing `char`, `text`, or `enum`; numeric and expression defaults pass through unchanged (for example `` default: `now()` ``).

## 6. Acceptance conditions

- Given a fixture with primary keys, unique, not-null, and default settings, the output contains one `CREATE TABLE` per table with the expected inline constraints.
- Given a fixture with a named `Ref:` line, the output contains exactly one matching `ALTER TABLE ... ADD CONSTRAINT ... FOREIGN KEY ...` statement.
- Generation is deterministic: the same AST always yields byte-identical SQL (reproducibility, [`NFR-005`](../01-requirements/non-functional-requirements.md)).
- Unit tests assert SQL text with table-driven tests over real DBML input ([`09-testing-strategy.md`](../09-testing-strategy.md) §3); executing the DDL against a real PostgreSQL is a stated success criterion ([`00-overview.md`](../00-overview.md) §11) but real-database integration tests are not yet in CI ([`README.md`](../README.md) §8).
