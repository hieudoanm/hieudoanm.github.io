# US-004: Generate an SVG diagram from DBML

## Story

**As a** developer
**I want** to generate an SVG ER diagram directly from a DBML file
**So that** I can publish a vector diagram with no external rendering tools installed

## Acceptance scenarios

- **Given** `schema.dbml`, **When** `dbml svg schema.dbml` runs, **Then** `schema.svg` is written and stdout reports `Generated SVG diagram: schema.svg`.
- **Given** tables, columns with keys, and enums, **When** the diagram is rendered, **Then** the document contains a box per table with `PK`/`UK` markers and type labels, and a box per enum titled `enum <name>` listing its values.
- **Given** a relationship whose tables both exist, **When** the diagram is rendered, **Then** a curve connects the two boxes with a dot marker at the referring end and an arrow marker at the referenced end.
- **Given** the output file, **When** it is parsed as XML or opened in a browser, **Then** it is well-formed and displays without any further assets — no Graphviz, mermaid-cli, or network access involved.
- **Given** a reference naming a table that does not exist, **When** the diagram is rendered, **Then** the document remains well-formed and simply omits that relationship line.

## Notes

- Layout constants, escaping, and edge cases are specified in [`FEATURE-04-SVG-Generation.md`](../02-features/FEATURE-04-SVG-Generation.md).
- Well-formedness is enforced by tests using `encoding/xml` ([`09-testing-strategy.md`](../09-testing-strategy.md) §3).
- `-o diagram.svg` selects a custom output path; the MCP transport offers the same rendering as `dbml_svg`.
