Frequently asked

Picked from real support conversations.

Does Landify need a build step?

No. Landify emits one flat HTML file with inline CSS. Open it in a browser or drop it on any static host.

Where do the colors come from?

The theme section lists eight base colors. Every other CSS token the page uses — surfaces, shades, tints, and text-on-accent contrast — is derived from them automatically.

Can I switch the page layout later?

Yes. Recreate the file with `landify new -t <type>` for the layout you want, then copy your site, theme, and footer blocks across.

Does this page need any JavaScript?

No. Questions render as native <details> rows, so the accordion works with markup alone.
