# User Stories

As a developer, I want to scaffold a landing page from one YAML file so that I
can ship a static site without a build pipeline.

As a contributor, I want strict validation and table-driven tests so that the
code stays correct as page types and themes are added.

As a maintainer, I want a hand-rolled MCP server over stdio so that LLM clients
can drive the build pipeline sandboxed to a workspace root.
