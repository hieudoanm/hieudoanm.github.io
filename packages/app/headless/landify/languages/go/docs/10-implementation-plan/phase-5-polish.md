# Phase 5 — Polish

MCP server (`landify mcp serve`) — six sandboxed tools over stdio for LLM
clients: scaffold, validate, build, types, themes, theme tokens; social meta
(`site.og`) — Open Graph + Twitter card tags in every layout, with site-level
fallbacks for title, description and site name; generated social card
(`og/og.svg`) — 1200 × 630 SVG from the theme and the card copy, written beside
the page on every build; card identity copy (`og.kicker`, `og.tags`).

Up next: configurable favicon; custom fonts and typography scale options;
analytical components (countdown, announcement bar, lead form handler);
accessibility audit (keyboard nav, focus states, contrast ratios).
