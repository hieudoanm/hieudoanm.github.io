# Landify

Build a flat landing page from a single YAML file. The output is plain HTML
and CSS with no runtime dependencies — open `index.html` in a browser or serve
it from any static host.

## Requirements

- Go 1.27+

## Usage

```sh
make build
./bin/landify new           # create landify.yaml with annotated placeholder content
./bin/landify new -t docs   # scaffold a docs layout instead of product
./bin/landify validate      # check the schema (strict: unknown fields are errors)
./bin/landify build         # write index.html from landify.yaml
```

## Flags

- `-f, --file` — YAML content file (default `landify.yaml`)
- `-o, --output` — generated page, `build` only (default `index.html`)
- `new -t, --type` — page layout to scaffold: product (default) | waitlist | event | download | app | pricing | portfolio | docs | faq | team | status | linktree
- `new -F, --force` — overwrite an existing `landify.yaml`

## Content

Both media slots render in the same 16:9 frame (1280 × 720):

- `hero.image.src` — the hero image (required)
- `demo.video.src` — an MP4 walkthrough (required); `demo.video.poster` is an
  optional still shown before playback

### Theme colors

`theme` takes only the eight base colors (plus the corner `radius`). Every
other token the page uses — surfaces, hairline borders, and text-on-accent
colors — is calculated from them (shades, tints, and WCAG contrast), so you
restyle the whole page from a handful of entries.

```yaml
theme:
  primary: '#0d9488'
  radius: '10px'
```

Fields you leave empty fall back to the defaults shipped with the template. The
placeholder generated by `landify new` lists every default.

The full schema — every field with a "required" note — is documented inline in
the YAML generated by `landify new`.
