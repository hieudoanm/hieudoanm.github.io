# pagify — Phase 7: Polish

## Goal

Accessibility, performance, and error-handling polish.

## Deliverables

- WCAG 2.1 AA: semantic HTML, focus states, contrast, reduced motion
- Performance budget: lightweight HTML/CSS/JS
- Actionable errors identifying what failed, which file/path, and context
- No-JavaScript usability verified

## Acceptance criteria

- Generated site is keyboard-navigable and contrast-compliant.
- Output size within performance budget.
- Errors contain path and context; no stack traces or secrets.
