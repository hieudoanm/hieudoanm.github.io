# pagify — US-003: Serve pages over JSON API

## Goal

Render individual pages through the `pagify serve` JSON API.

## Acceptance criteria

1. Given `pagify serve` is running with `--root` set.
2. When `POST /api/v1/build` names a content path.
3. Then rendered HTML is returned in memory, nothing written to disk.
4. And `GET /api/v1/health`, `/api/v1/openapi.json`, `/api/v1/docs` describe the API.
5. And no request can read outside `--root`.
