# pagify — US-001: Build a site from Markdown

## Goal

Turn a directory of Markdown files into a deployable static website.

## Acceptance criteria

1. Given a directory with `index.md` and `getting-started.md`.
2. When the user runs `pagify build ./docs`.
3. Then `dist/index.html` and `dist/getting-started/index.html` exist.
4. And `dist/` contains the theme CSS, JS, and a search index.
5. And the site opens statically with no server.
