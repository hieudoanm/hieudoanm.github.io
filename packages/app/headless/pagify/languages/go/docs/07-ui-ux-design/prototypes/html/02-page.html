Creating your first page

A walkthrough of authoring, theming, and building a static site.

pagify turns Markdown files into a navigable static website with a single command. No build step, no frontend framework, no runtime dependency.

Authoring

Start with an index.md in your docs/ directory. pagify discovers Markdown files, parses them, and renders each page with the default theme.
