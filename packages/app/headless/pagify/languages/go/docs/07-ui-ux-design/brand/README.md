# pagify — Brand

Brand tokens, logos, and wordmarks for the pagify default theme.

| File                                | Purpose              |
| ----------------------------------- | -------------------- |
| [`brand.sh`](brand.sh)              | Asset generation helper |
| [`images/`](images/)                | Raster brand assets (PNG) |
| [`svg/`](svg/)                      | Vector brand assets (SVG) |

## Assets

- `logo-mark-dark.svg` / `logo-mark-light.svg` — icon mark
- `logo-text-dark.svg` / `logo-text-light.svg` — wordmark

See [`07-ui-ux-design.md`](../../07-ui-ux-design.md) for design direction.
