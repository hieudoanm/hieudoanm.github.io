Features

Everything you need for beautiful documentation sites.

⚡

Zero Configuration

Point pagify at a directory of Markdown files and get a complete site. No config files, no build step, no dependencies.

📝

Markdown First

Write content in standard Markdown with GitHub-flavored extensions: tables, task lists, footnotes, callouts, and more.

🔍

Built-in Search

Client-side search index generated at build time. No backend required, works on any static host.

🌙

Dark Mode

Automatic OS detection with manual toggle. Persists preference in localStorage.

📱

Responsive

Sidebar navigation on desktop, collapsible drawer on mobile. Works on all screen sizes.

🚀

Single Binary

One Go binary with embedded assets. No Node.js, no Python, no runtime dependencies. Install and run.
