# v0.0.2

Released: December 20, 2023

## Added

- **Themes** — Pluggable template + asset tree, embedded via `go:embed`
- **Navigation** — Generated from the file tree; `index.md` becomes a section landing page
- **Link rewriting** — `.md` links rewritten to clean URLs
- **Frontmatter** — Page metadata: title, description, order, label, draft
- **Site config** — `pagify.yaml` at the content root

## Fixed

- Output directory now cleared before each build so deleted pages do not survive
