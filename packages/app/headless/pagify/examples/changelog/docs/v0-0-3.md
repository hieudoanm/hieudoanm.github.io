# v0.0.3

Released: January 5, 2024

## Added

- **Search index** — Client-side search over a generated `search-index.json`
- **Callouts** — GitHub-style `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!DANGER]`
- **Preview server** — `pagify preview` rebuilds on every request
- **Goldmark v2** — GFM, footnotes, auto heading IDs, raw HTML passthrough
- **Dark/light theme** — Automatic OS detection with manual toggle

## Fixed

- Sidebar now takes full viewport height on all browsers
- Callout aliases (`info`, `success`, `check`, `caution`, `attention`, `error`) accepted
