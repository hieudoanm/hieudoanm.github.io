# v0.1.0

Released: January 15, 2024

## Added

- **Zero-configuration builds** — Point at a directory of Markdown files, get a complete site
- **GitHub-flavored Markdown** — Tables, task lists, strikethrough, autolinks, footnotes
- **Callouts** — `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!DANGER]` with aliases
- **Built-in search** — Client-side search index, no backend required
- **Dark/light theme** — Automatic OS detection, manual toggle, localStorage persistence
- **Responsive design** — Sidebar on desktop, drawer on mobile
- **Syntax highlighting** — Via CSS, no JavaScript required
- **Cross-page links** — `.md` links rewritten to clean URLs
- **Frontmatter** — Page metadata (title, description, order, label, draft)
- **Site config via frontmatter** — title, language, basePath, theme, footer in index.md
- **Local dev server** — `pagify serve` with live rebuild
- **MCP server** — `pagify mcp` for AI tool integration
- **Single binary** — Embedded assets, no Node.js, no runtime dependencies
