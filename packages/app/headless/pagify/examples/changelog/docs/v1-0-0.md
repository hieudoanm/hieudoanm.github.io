# v1.0.0

Released: September 1, 2024

## Added

- **Stable API** — Public command surface is now frozen
- **Plugin system** — Hooks for custom themes, renderers and link resolvers
- **Multi-language support** — `language` frontmatter and i18n navigation
- **`pagify check`** — Link validation command
- **OpenAPI docs** — `pagify serve` exposes `/api/v1/openapi.json` and Swagger UI
- **Workspace confinement** — `--root` bounds all file access for the API server

## Changed

- `pagify serve` replaces the preview server as the API entry point
- Theme assets now copied through `fs.FS` rather than walking directories

## Fixed

- API server no longer reads outside its `--root`
- Navigation groups with no `index.md` render correctly

## Security

- All content paths resolved through `internal/workspace`
