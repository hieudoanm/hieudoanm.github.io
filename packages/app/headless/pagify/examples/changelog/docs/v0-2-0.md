# v0.2.0

Released: March 1, 2024

## Added

- **Graph command** — `pagify graph` scans Markdown and emits a link graph
- **Interactive HTML visualization** — Offline vis-network graph view
- **JSON graph export** — `--format json` for renderer-independent data
- **Graph dot export** — `--format dot` for Graphviz
- **Obsidian-inspired theme** — Dark palette, purple nodes, force-directed layout
- **Graph search and inspection** — Search, hover tooltips, connected-file details

## Changed

- `pagify graph` defaults to writing `graph.dot`, `graph.json` and `graph.html`

## Fixed

- Graph output directory paths now resolve correctly
