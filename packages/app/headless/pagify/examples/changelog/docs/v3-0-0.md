# v3.0.0

Released: October 1, 2025

## Added

- **MCP server** — `pagify mcp` exposes pagify as an AI tool over Model Context Protocol
- **Workspace confinement** — Every content path resolved through `internal/workspace`, so the API cannot read outside `--root`
- **OpenAPI 3.1** — `/api/v1/openapi.json` and Swagger UI at `/api/v1/docs`
- **Health endpoint** — `/api/v1/health` for load balancers and CI
- **In-memory build** — `POST /api/v1/build` renders one page without writing to disk
- **Frontmatter-driven config** — Site-wide settings live in `index.md` frontmatter

## Changed

- `pagify serve` is the single API entry point; preview is a thin wrapper
- All file access confined to `--root`

## Security

- All content paths resolved through `internal/workspace`
