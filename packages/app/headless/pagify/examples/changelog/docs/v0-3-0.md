# v0.3.0

Released: May 15, 2024

## Added

- **Wikilink extraction** — `[[target]]`, `[[target|alias]]`, `[[target#frag]]`
- **Standard Markdown link extraction** — `[text](target)` alongside wikilinks
- **Extensionless link resolution** — `[Guide](guide/index)` resolves to `guide/index.md`
- **Fenced code block skipping** — Links inside ``` ``` ``` blocks are ignored
- **Broken link detection** — Unresolved targets are marked, not silently dropped
- **Outside-root detection** — Links escaping the scan root are reported
- **Duplicate edge removal** — Normalized unordered pairs collapse
- **Deterministic ordering** — Nodes and edges sorted before serialization

## Changed

- Graph extractor refactored into `internal/graph` with separate renderer

## Fixed

- Nested fenced code blocks now parse correctly
