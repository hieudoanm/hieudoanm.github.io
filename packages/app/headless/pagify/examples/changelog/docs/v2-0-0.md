# v2.0.0

Released: February 10, 2025

## Added

- **Pluggable architecture** — Themes, renderers and resolvers are now first-class extensions
- **Custom themes** — Embed a template + asset tree and resolve it by name in `build.Build`
- **Plugin hooks** — Before/after build, before/after render, custom link resolution
- **Asset tree API** — `fs.FS`-based asset copying with no directory walking
- **Config validation** — `pagify.yaml` is validated against a schema; unparsable configs fail loudly

## Changed

- `internal/theme` replaces the monolithic default theme with a composable `Theme` type
- `internal/build` restructured around `loadSite` and `writePages`
- `pagify preview` rebuilds on every request instead of watching the filesystem

## Removed

- Legacy `serve` command (replaced by `pagify serve` with OpenAPI)
