Overview

A tiny key/value server that talks the same protocol Redis clients already speak, keeping the whole store in memory.

Redis-style protocol

PING, SET, GET, KEYS, and DEL use the simple framing existing clients and tools understand.

In-memory storage

Every value lives in RAM, so reads and writes never touch the disk — fastest when data fits in memory.

Two implementations

The same kv binary is built twice, once with a C compiler and once with a C++ compiler, from matching sources.

Server or library

Run it standalone on a port like Redis, or link it into your own C or C++ program.
