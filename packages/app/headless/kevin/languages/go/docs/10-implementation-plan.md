# KeVIN (Go) — Implementation Plan

## 1. Purpose

Phased delivery plan aligned with ROADMAP.

## 2. Phases

- Phase 1 — Foundation (shipped): Core store, TCP server, CLI, basic tests
- Phase 2 — Protocol & behavior (shipped): TTL/EXPIRE, variadic ops, extended commands
- Phase 3 — Reliability & ops (in progress): Snapshots, graceful shutdown, structured logging, benchmarks
- Phase 4 — MCP (shipped): JSON-RPC 2.0 MCP server with tools, backends
- Phase 5 — Ecosystem: Installation scripts, packaging, cross-platform
- Phase 6 — Production: Pluggable storage, auth, metrics

See [ROADMAP.md](./04-architecture/ROADMAP.md) for detailed checklist.
