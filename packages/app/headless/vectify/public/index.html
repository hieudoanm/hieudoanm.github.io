Pixels, on purpose.

Vectify traces flat art into SVG by implementing the whole chain itself — quantisation, region growing, boundary walking, simplification, and least-squares Bezier fitting. No tracing library underneath.

Read the architecture Source on GitHub

The pipeline

One card per stage of the tracer, in the order the data flows.

🎨

Quantise

A luminance threshold, or a median-cut palette assigned to the nearest swatch. Deterministic, and flattened onto the backdrop first so a transparent pixel cannot leak a bogus colour.

🧩

Segment

An 8-connected flood fill groups pixels into regions, dropping any below the area floor. Traced per region, so two blobs sharing a colour never inherit each other's outlines.

✏️

Contour

Boundary edges are emitted per exposed side, then chained into closed loops. Direction is preserved so holes cut out without relying on winding order.

📉

Simplify

Douglas–Peucker over each closed loop, with a fallback split at the point furthest from the start so the loop can recurse into open chains.

📈

Fit

Least-squares fit, measure, split. With both end tangents fixed the fit is linear, so the optimal control points come from one small solve.

✅

Measure it

The emitted SVG is rasterized by an independent renderer and scored against the source: MAE, SSIM, edge similarity, and the primitive count it cost.

Watch it trace

Five commands, roughly fifteen seconds. The CLI is a thin shell over the same library the HTTP API serves, so nothing here is a mock.
