# Backbone — US-001: Run a self-hosted backend from one binary

## Goal

Stand up a complete BaaS with a single static binary and no external services.

## Acceptance criteria

1. Given the `backbone` binary (or Docker image).
2. When the user runs `./backbone`.
3. Then SQLite opens at `~/.backbone/backbone.db` and HTTP serves on `:8080`.
4. And `GET /api/health` returns `{"status":"ok"}`.
5. And the admin dashboard is reachable at `/`.
