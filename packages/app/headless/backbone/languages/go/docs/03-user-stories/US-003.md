# Backbone — US-003: Use the REST API with JWT auth

## Goal

Integrate a client application with the Backbone REST API.

## Acceptance criteria

1. Given `POST /api/auth/register` and `POST /api/auth/login`.
2. When the user registers and logs in.
3. Then a valid HS256 JWT (72h) is returned.
4. And `Authorization: Bearer <token>` grants access to protected routes.
5. And RBAC enforces role ↔ collection permissions.
