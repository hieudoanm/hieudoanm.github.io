# Backbone — US-004: Receive real-time updates

## Goal

Stream live updates via WebSocket or Server-Sent Events.

## Acceptance criteria

1. Given `/ws` or `/api/pubsub/{name}/stream`.
2. When a record is created or a message is published.
3. Then connected clients receive the update in real time.
4. And WS connections use 30s ping/keepalive.
