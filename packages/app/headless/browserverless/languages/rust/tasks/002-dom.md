# Task 002: DOM Tree

## Feature

### Status

completed

### Goal

Implement the DOM tree data structure with node creation, traversal, and attribute support.

### Requirements

- Node types: Document, Element, Text, Comment
- NodeId-based addressing
- Parent/child relationships
- Attribute storage for elements
- Display trait for debugging

### Non-goals

- Full DOM API (querySelector, etc.)
- Event system
- Shadow DOM

### Implementation

- `Dom` struct with `Vec<TreeNode>` storage
- `NodeId` as `usize` index
- Methods: `create_element`, `create_text`, `create_comment`, `set_attribute`, `get`, `parent`, `children`
- `Display` implementation for tree visualization

### Verification

- 8 unit tests pass
- `cargo test -p dom`

### Acceptance Criteria

- Can create document root
- Can create nested elements
- Can set and get attributes
- Can create text and comment nodes

### Notes

- Simple arena-based allocation
- No garbage collection needed for MVP
