# CircleCI Best Practices: Workflow Checklist

A practical run sheet for applying [CircleCI Best Practices](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Define the task and success criteria
- [ ] Apply the most relevant guidance in the skill
- [ ] Check assumptions and edge cases
- [ ] Validate the outcome against project requirements

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
