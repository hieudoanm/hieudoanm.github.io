# Solution Architecture Review

- [ ] Outcomes, scope, constraints, and assumptions are explicit.
- [ ] Current state and affected stakeholders are understood.
- [ ] Quality attributes have measurable scenarios and verification plans.
- [ ] Boundaries, data ownership, trust zones, and integrations are clear.
- [ ] Viable alternatives and consequences are documented.
- [ ] Failure handling, security, observability, and ownership are designed.
- [ ] Migration, rollback, cost, and exit paths are feasible.
- [ ] Highest-risk assumptions have owners and validation evidence.
