# Example: Legacy Modernization

**Illustrative scenario; no specific legacy platform is implied.**

A business-critical application is difficult to change, but a rewrite would create a large delivery and data-migration risk. The architecture team maps high-change areas, dependencies, data ownership, and operational constraints.

Options include targeted modularization, a strangler migration, or replacement. The decision compares incremental value, coexistence cost, compatibility, rollback, and team capacity. The first slice moves one bounded capability while retaining a tested route back; the team measures whether coupling and release risk actually improve.
