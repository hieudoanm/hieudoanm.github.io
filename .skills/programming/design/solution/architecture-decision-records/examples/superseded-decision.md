# Example: Superseded Decision

**Illustrative lifecycle record.**

A prior decision selected a self-managed service because managed options did not meet a documented requirement. Later, the requirement changes and the managed service adds required controls.

Create a new record with updated evidence, migration and exit costs, and operational implications. Mark the old record superseded and link both ways. Do not erase the original context or imply the former choice was irrational given what was known then.
