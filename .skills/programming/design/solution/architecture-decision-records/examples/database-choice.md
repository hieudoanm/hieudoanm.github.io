# Example: Database Choice

**Illustrative decision; no product or vendor is recommended.**

**Context:** A new capability needs durable records and must support defined query and recovery needs. Existing platform support and operator experience are known constraints.

**Options:** extend the current relational platform, adopt a document store, or use a managed service. Compare data shape, transaction needs, query patterns, backup/restore, compliance, operations, migration, and exit cost.

**Decision:** select only after workload and recovery requirements are measured. Record unresolved scale assumptions and a validation plan; do not choose based on a generic “scale” claim.
