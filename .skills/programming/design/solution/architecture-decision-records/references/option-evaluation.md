# Option Evaluation

Compare options against decision drivers, using evidence appropriate to the consequence and reversibility of the choice.

| Driver                     | Evidence / uncertainty | Option A | Option B | Status quo |
| -------------------------- | ---------------------- | -------- | -------- | ---------- |
| Requirement fit            |                        |          |          |            |
| Quality targets            |                        |          |          |            |
| Security / compliance      |                        |          |          |            |
| Build and migration effort |                        |          |          |            |
| Operations and support     |                        |          |          |            |
| Reversibility / exit       |                        |          |          |            |

Avoid pretending that qualitative judgments are precise measurements. If scores or weights are used, explain their source and sensitivity. Include an experiment or spike when it can resolve a material uncertainty more cheaply than debate.
