# Solution Design and Architecture

A focused collection for turning requirements and constraints into an implementable, reviewable system design. Start with [solution-architecture](solution-architecture/SKILL.md), then use the specialized skills for decisions, quality attributes, system boundaries, and integrations.

## Skills

- [Solution architecture](solution-architecture/SKILL.md) — end-to-end design workflow and trade-offs.
- [Architecture decision records](architecture-decision-records/SKILL.md) — capture consequential choices and their consequences.
- [Quality-attribute analysis](quality-attribute-analysis/SKILL.md) — make reliability, performance, security, cost, and operability testable.
- [System context and boundaries](system-context-and-boundaries/SKILL.md) — identify actors, responsibilities, trust boundaries, and service ownership.
- [Integration architecture](integration-architecture/SKILL.md) — design API, event, and data contracts between components.

Choose the smallest set of skills needed for the design. These guides are technology-neutral; use stack-specific skills for implementation details.
