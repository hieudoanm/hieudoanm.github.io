# Example: Availability Scenario

**Illustrative requirement, not an SLA.**

During normal operation and a single dependency failure, a user can complete the critical workflow or receives a clear degraded response. The team must define the service boundary, observation point, time window, error budget, exclusions, and dependency assumptions with stakeholders.

Verification includes dependency-failure exercises, monitoring review, and incident procedures. Numeric targets should be set from business impact and operating evidence, not copied from this example.
