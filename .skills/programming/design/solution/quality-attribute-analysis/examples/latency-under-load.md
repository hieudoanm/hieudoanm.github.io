# Example: Latency Under Load

**Illustrative test scenario; thresholds must be supplied by the product team.**

For the primary read workflow, measure client-observed latency by request class at expected and peak load using representative payloads. Record percentile targets, error rate, resource use, dependency latency, and test environment.

Repeat with cold and warm cache states if both occur in production. Compare changes against the same workload and configuration; do not report only the fastest run.
