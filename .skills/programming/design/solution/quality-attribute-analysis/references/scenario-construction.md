# Scenario Construction

Write a quality scenario with source, stimulus, context, response, and measurable response. Define workload and measurement boundary, such as client-observed latency versus server processing time.

Weak: “The system must be scalable.”

Stronger: “During a planned twofold increase in concurrent requests, the service maintains the agreed error and latency targets without manual intervention.”

Targets should come from user needs, contracts, operational evidence, or explicit business decisions—not arbitrary round numbers. Record target owner, measurement method, and confidence in the assumption. Distinguish minimum acceptable service from aspirational improvement.
