# Trust-Flow Checklist

- [ ] Actor and identity are known at each crossing.
- [ ] Data classification and purpose are documented.
- [ ] Authentication, authorization, and validation owners are clear.
- [ ] Encryption, secrets, and key responsibilities are addressed.
- [ ] Logs and telemetry do not expose restricted data.
- [ ] Failure and abuse cases are considered.
- [ ] Third-party or administrative paths are included.
- [ ] Security owner reviewed material assumptions.
