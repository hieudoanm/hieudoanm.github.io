# Security and Observability

Authenticate service identities and authorize actions and data scope. Validate inputs and payload sizes; protect secrets and sensitive fields in transit, storage, logs, traces, and dead-letter stores. Apply least privilege and document third-party data handling.

Instrument request or message correlation, outcome, latency, retries, and failure category. Avoid logging credentials, tokens, or unnecessary personal data. Define alert thresholds and operational ownership; a metric without an action path is not sufficient monitoring.

Review trust boundaries, audit needs, retention, and incident response with the responsible security and privacy owners.
