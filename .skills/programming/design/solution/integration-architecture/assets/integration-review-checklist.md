# Integration Review Checklist

- [ ] Producer, consumers, ownership, and source of truth are clear.
- [ ] Interaction pattern fits timing, consistency, and workload.
- [ ] Contract semantics and schema evolution are specified.
- [ ] Identity, authorization, validation, and sensitive data handling are covered.
- [ ] Timeouts, retries, duplicates, ordering, and partial failures are addressed.
- [ ] Observability, reconciliation, and operational ownership exist.
- [ ] Compatibility, rollout, rollback, and deprecation are planned.
