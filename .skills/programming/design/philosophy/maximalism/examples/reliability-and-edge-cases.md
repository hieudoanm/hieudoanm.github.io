# Maximalism: 1. Core Principles

## Scenario

A project is working on **1. core principles** for Maximalism. The team needs to apply this guidance without losing the constraints that make the skill relevant.

## Worked example

Use the following source guidance as a short decision checklist:

- **Ornament is structure** — decoration that repeats becomes a visual grammar.
Filler decoration communicates nothing; patterned space communicates energy,
place, and era.
- **Systematic or nothing** — repetition plus alignment. The same motif applied
consistently reads as language; applied randomly it reads as an error.
- **Density as generosity** — a catalogue that shows everything rewards the reader
who wants it. Hiding is the minimalism failure mode, and sometimes it is right.

2. Check the result against the section's intended outcome and the surrounding skill guidance.
3. Validate relevant edge cases with project-specific tests or review.
