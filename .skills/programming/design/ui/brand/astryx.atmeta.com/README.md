# Astryx Design System

Use Astryx when a project needs a customizable component system with semantic
tokens and theme variants. This folder contains a practical guide and a
standalone token-driven example; it does not replace the official Astryx
package or documentation.

## Important caveat

Astryx supports theme-scoped overrides. Confirm the package version and active
theme before applying any token or component guidance. The CSS snapshot here is
a dated reference from the published base stylesheet, not a production theme
bundle.
