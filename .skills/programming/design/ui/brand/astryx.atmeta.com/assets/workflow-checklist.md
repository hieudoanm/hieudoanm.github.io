# Astryx Design System: Workflow Checklist

A practical run sheet for applying [Astryx Design System](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] **Inspect the project.** Find its Astryx package/version, theme setup,
- [ ] **Choose the visual target.** Decide whether to use the default Astryx theme,
- [ ] **Find the intended primitive.** Check the current component docs and
- [ ] **Compose with tokens.** Use the smallest set of components that satisfies
- [ ] **Check responsive and interactive behavior.** Test narrow layouts,
- [ ] **Validate the implementation.** Run the project’s formatter, type check,

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
