# Maximalism: Decision Record

Use this record when applying [Maximalism](../SKILL.md) to a concrete project decision.

## Context

Apply maximalist principles to web/app UI — deliberate density, ornament as structure, saturation, and composition that ceremony rather than recedes. Covers the systematicness rule, zone strategy for keeping pattern off text, scale contrast as the engine, and where maximalism fails. Use for brand and campaign surfaces, editorial and cultural products, rich product categories, and anything where expression is the product rather than a distraction from it.

Four philosophies in this directory form one map. Minimalism and maximalism vary **how much** is present; flat and brutalism vary **how finished** it looks.
