# Minimalism as a Method: Workflow Checklist

A practical run sheet for applying [Minimalism as a Method](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] **State the job in one sentence.** "Confirm a refund." If you cannot, minimalism
- [ ] **Inventory what's on screen.** Every element, with what it is _for_. Most
- [ ] **Mark each as primary, supporting, or incidental.** Anything that isn't
- [ ] **Cut in order of increasing cost** — cheapest to reverse first, so mistakes
- [ ] **Verify each cut by task, not by eye.** Walk the job end to end. Screenshot

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
