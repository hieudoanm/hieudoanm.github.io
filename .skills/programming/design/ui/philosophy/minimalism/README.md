# Minimalism as a Method

Minimalism is not a look. It is a **method of subtraction applied to a stated purpose** — and "less" has no value on its own. A screen with one button is minimal and useless. Minimalism only counts when the thing got _better at its job_.

## When to use

Use when asked to simplify or clean up UI, when a screen feels heavy or cluttered, or when reviewing whether a reduction actually improved the interface.
