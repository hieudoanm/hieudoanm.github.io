# Flat Design: Decision Record

Use this record when applying [Flat Design](../SKILL.md) to a concrete project decision.

## Context

Apply flat design to web/app UI — reject depth cues, let colour blocks, borders, and typography carry hierarchy. Covers the post-skeuomorphic shift, expressing elevation without shadows, iconography and colour discipline, and when "flat" has hardened into a dated statement. Use for dashboards, SaaS, mobile apps, and any dense data UI that wants to read as clear and modern.

Four philosophies in this directory form one map. Minimalism and maximalism vary **how much** is present; flat and brutalism vary **how finished** it looks.
