# Insomnia

Insomnia is an open-source API client with Git sync, a request designer, and test scripting on the same model as Postman. Its distinguishing feature is **designed API documents**: you can build a resource by describing its fields, and Insomnia derives the requests, environment variables, and mock responses from that description.
