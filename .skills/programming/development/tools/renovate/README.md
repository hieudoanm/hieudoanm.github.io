# Renovate

Renovate is a dependency-update bot that opens pull requests across every ecosystem, and its real value is not the updates themselves — plenty of bots do that — but **the policy you encode about which updates group together, which merge automatically, and when a major is acceptable**. A Renovate config is a statement of your team's risk posture. Practical Renovate work is about **separating low-risk from high-risk updates...

## When to use

Use when setting up, or reviewing, dependency update automation.
