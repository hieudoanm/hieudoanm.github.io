# Zed

Zed is a high-performance native code editor: GPU-rendered, fast on large files, and built around language servers with a small, curated default extension set. Its trade-off against VS Code is deliberate — **fewer extensions and a smaller surface, in exchange for speed and a settings model that is committed as a project file**.
