# Cursor

Cursor is a VS Code fork with AI integrated into the editor: inline completion, a chat that can read the project, and an agent mode that plans and applies multi-file changes. Its power is real; its failure mode is also real — **a plausible-looking diff that silently drops an edge case, and an editor whose default behaviour is to write code you did not ask it to write**.
