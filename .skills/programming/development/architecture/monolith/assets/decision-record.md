Use this record when applying [Monolithic Architecture Best Practices](../SKILL.md) to a concrete project decision.

## Context

Best practices for designing and implementing monolithic applications. Use when planning, structuring, or reviewing monolithic architecture — covers module organization, scalability, maintainability, and evolution strategies.

Monolithic architecture is a traditional software design where the application is built as a single, unified unit. Best practice is to structure monoliths with clear module boundaries, implement proper separation of concerns, and design for eventual evolution into microservices if needed.
