# bulma: Basic Usage

Bulma — free, open-source CSS framework based on flexbox with minimal setup and a simple, modern aesthetic.

## Scenario

Use this example as a starting point when applying **bulma** to a small, representative task. It demonstrates the pattern shown in the skill’s **1. Installation and Setup** guidance; adapt names, configuration, and error handling to the actual project.

## Example

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bulma@1.0.4/css/bulma.min.css"
/>
```

- Treat this as a focused pattern, not a complete production implementation.
