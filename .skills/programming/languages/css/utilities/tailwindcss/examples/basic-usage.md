# tailwindcss: Basic Usage

Tailwind CSS — utility-first CSS framework for rapidly building custom UIs without leaving your HTML.

## Scenario

Use this example as a starting point when applying **tailwindcss** to a small, representative task. It demonstrates the pattern shown in the skill’s **1. Installation and Setup (v3)** guidance; adapt names, configuration, and error handling to the actual project.

```javascript
// postcss.config.js
export default {

  },
};
```
