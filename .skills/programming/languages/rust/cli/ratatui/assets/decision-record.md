# Ratatui Design Best Practices: Decision Record

Use this record when applying [Ratatui Design Best Practices](../SKILL.md) to a concrete project decision.

## Context

Best practices for building visually polished terminal UIs with Ratatui (Rust). Use when creating, styling, or reviewing a Ratatui TUI app — covers layout constraints, color, widgets, and theming patterns with suggested values.

Ratatui is immediate-mode: every frame you fully redraw the UI from a Frame. Visual polish comes from disciplined use of Style, Layout constraints, and consistent widget choices — there's no CSS-equivalent to fall back on.
