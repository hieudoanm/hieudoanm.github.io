# Visual Studio

Visual Studio is the full-featured Windows IDE: Roslyn compilation and IntelliSense, the designer, a real debugger with Hot Reload, profilers, and a test runner. It is also the heaviest tool in the .NET ecosystem, and its main source of friction is that **it stores configuration in places CI never reads**.
