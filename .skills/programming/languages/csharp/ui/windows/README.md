# Windows App Development

Windows desktop development in C# has converged on the **Windows App SDK**: a NuGet-distributed framework providing WinUI 3, the modern Fluent UI, plus modern windowing, notifications, and AI APIs. It is the recommended platform for new Windows apps, and it can be adopted by existing WPF, Windows Forms, and Win32 apps for platform features without a rewrite.
