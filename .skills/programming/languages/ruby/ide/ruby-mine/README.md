# RubyMine

RubyMine is JetBrains' Ruby and Rails IDE, with a mature Rails plugin set: navigation for routes, models, and associations, Rails-aware generators, and a debugger that handles Ruby idioms well. Its main risk is **the IDE's Ruby environment drifting from the one Bundler installs**, which produces a project that behaves differently in the editor than in the terminal.
