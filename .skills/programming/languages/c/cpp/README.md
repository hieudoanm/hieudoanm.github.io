# C++ Best Practices

Modern C++ (C++20/23) is C with type safety, RAII, move semantics, and the STL bolted on — and the discipline is the product. Practical C++ leans on **RAII for every resource, ownership expressed by types** (unique_ptr/shared_ptr/references), **value semantics with deliberate move paths**, **exceptions for genuine failures (or a single no-exceptions policy)**, and **const correctness enforced by the compiler**.
