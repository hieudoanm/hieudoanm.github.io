# Android Studio

Android Studio is the IntelliJ-based IDE for Android: it owns the Gradle sync, the Layout Editor and Compose tooling, the emulator, and the profilers. Its defining trait is that **it is a front end over a build system you must also be able to run from a terminal** — a project that only builds in the IDE is a project that will not build in CI.
