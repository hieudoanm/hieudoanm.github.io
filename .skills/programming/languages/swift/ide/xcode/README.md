# Xcode

Xcode is the compiler driver, build system, simulator, debugger, and profiler for every Apple platform — and it is also a large amount of IDE state that does not belong in version control. Practical Xcode work is mostly about **knowing which files are generated and must be ignored, keeping build configuration out of the IDE, and making sure CI compiles what you compiled locally**.
