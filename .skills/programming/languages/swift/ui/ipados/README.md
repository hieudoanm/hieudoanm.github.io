# iPadOS Development

iPadOS is not an iPhone with a bigger screen — since iPadOS 26 it runs a **full desktop-style windowing system**: resizable windows, a menu bar, traffic-light controls, and free movement between displays. Practical iPad work leans on **NavigationSplitView doing the adapting for you, zero device or orientation checks, and layouts that stay sane down to 375pt wide** — while SwiftUI conventions live in swiftui.md, language...
