# Scala Best Practices

Scala (3) is a statically-typed, expressive language on the JVM that threads functional and object-oriented style. Practical Scala leans on **immutability as the default, ADTs (enum/case classes) for domain models, exhaustive pattern matching via the compiler**, and **Option/Either/Try over null-and-throw**.
