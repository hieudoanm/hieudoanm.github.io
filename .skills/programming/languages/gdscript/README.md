# GDScript Best Practices

GDScript is **Godot's primary scripting language** — Python-flavored syntax with static typing, first-class signals, and a scene-tree model where nodes communicate via @onready, export, and signals. Practical GDScript leans on **strong typing (: int, -> void), signal-based decoupling over direct node pokes, exported vars for tweakable parameters, and correct loop hooks (_ready/_process/_physics_process)** — the tree, not...
