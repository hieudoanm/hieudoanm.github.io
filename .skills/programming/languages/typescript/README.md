# TypeScript Best Practices

TypeScript is a superset of JavaScript whose value is entirely in _types that describe your data honestly_. Most of the classic TS pain — any sneaking back in, unions collapsing to string, data arriving at the boundary unvalidated — is avoided by treating the type system as the contract: lean on strict, model the domain with unions and branded types, validate at the edges, and let the compiler be the reviewer....

## When to use

Use when writing, structuring, or reviewing TypeScript code.
