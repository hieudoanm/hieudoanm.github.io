# Hapi.js Backend Best Practices

hapi is a configuration-driven Node.js framework built on plugins and a rich request lifecycle: you _describe_ servers, routes, validation, auth, and cache in config objects, and hapi enforces them. Its strengths — explicit lifecycle hooks, Joi validation, Boom errors, built-in caching — shine in large, stable APIs.
