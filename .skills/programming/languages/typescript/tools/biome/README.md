# Biome

Biome is a **single Rust binary that formats, lints, and organizes imports**, replacing the eslint.md + prettier.md pairing with one config file. That consolidation is genuinely valuable — 20-30x faster, one config, one binary — but it is a real trade, because Biome's ecosystem is a fraction of ESLint's.
