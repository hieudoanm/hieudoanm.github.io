# Auth.js Best Practices

Auth.js (NextAuth) is the **authentication library for Next.js/React apps** — provider-agnostic (Credentials, OAuth/OIDC, Email), with **session strategy (jwt/database), callbacks, and adapters** as its knobs. Practical Auth.js leans on **a single, typed auth config with providers declared for the app's real flows, a deliberate session strategy (JWT for stateless/edge, DB for long-lived/roles), callbacks that attach...
