# Brain.js Best Practices

Brain.js is a **simple neural network library for JS** — new brain.NeuralNetwork()/brain.recurrent.LSTM trained on input/output arrays with JSON serialization built in. Practical Brain.js leans on **input→output array mapping (normalize!), training with tolerance/iterations and observed error, and toJSON/fromJSON for deploying trained nets — plus the pragmatic ceiling: small fixed-topology nets** — it's the HTML5-era...

## When to use

Use when writing, structuring, or reviewing Brain.js.
