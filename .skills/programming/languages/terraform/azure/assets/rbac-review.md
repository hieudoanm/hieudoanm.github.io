# Azure RBAC Change Review

- [ ] Principal identity, tenant, type, and owner are verified.
- [ ] Role definition is minimal and appropriate for the task.
- [ ] Scope is the narrowest practical management group, subscription, group, or resource.
- [ ] Inherited assignments, deny assignments, and policy are considered.
- [ ] No duplicate or competing state owns the assignment.
- [ ] Directory lookup and assignment propagation are handled safely.
- [ ] Runtime identity is separate from deployment identity where appropriate.
- [ ] Rollback and access-recovery owner are identified.
