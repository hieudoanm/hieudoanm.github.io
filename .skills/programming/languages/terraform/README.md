# Terraform

Use the core guide for portable Terraform practices, then the provider guide for cloud-specific authentication, state, IAM, and resource patterns.

| Skill                                       | Use for                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------- |
| [Terraform Core](./SKILL.md)                | HCL, modules, state, plans, lifecycle, validation, and safe change workflow     |
| [Terraform on AWS](./aws/SKILL.md)          | AWS provider, account and role boundaries, IAM, and AWS resource design         |
| [Terraform on Azure](./azure/SKILL.md)      | AzureRM provider, subscription boundaries, identity, and Azure resource design  |
| [Terraform on Google Cloud](./gcp/SKILL.md) | Google provider, project boundaries, identity, and Google Cloud resource design |

Each skill has exactly four references, examples, and reusable assets. Provider-specific instructions supplement—not replace—the core guide. Confirm provider and Terraform behavior against the project lock file and current official documentation.
