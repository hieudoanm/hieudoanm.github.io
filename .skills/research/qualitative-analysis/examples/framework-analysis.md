# Example: Framework Analysis

**Illustrative workflow; no participant results are asserted.**

## Question

What barriers and facilitators shape access to a community health service across different user groups?

## Framework

After familiarization, the team develops a thematic framework informed by the question and open to emergent concepts. Each case is summarized into a matrix: rows are participants or cases; columns are framework categories; cells retain concise summaries and source locations.

The matrix supports comparison across cases and groups but should not detach excerpts from context. Revise the framework when material does not fit; log changes and revisit earlier cases. Report both recurring patterns and meaningful differences without treating the matrix as a quantitative prevalence table.
