# Evidence-to-Claim Matrix

Use the matrix to check that interpretations are supported and bounded.

| Analytic claim | Supporting cases / excerpts | Variation or counterexample | Context needed | Alternative reading | Reporting decision |
|---|---|---|---|---|---|
| | | | | | |

Before reporting, verify excerpts against source material, remove or mask identifying details as required, and explain how the evidence supports the interpretation. Avoid using quotations as decoration or implying that a quote alone proves a broad claim.
