# Example: Response to Reviewers

**Illustrative response format; not a real editorial exchange.**

> **Comment:** Please explain how missing primary outcomes were handled.
>
> **Response:** We agree that the original description was incomplete. We have added the prespecified missing-data approach and a sensitivity analysis under an alternative assumption. The Methods now describe this on page X, lines Y–Z; results are reported in Table S1. The sensitivity analysis is post hoc and is labeled accordingly.

If disagreeing, state the reason and provide evidence without dismissing the concern.
