# Aims and Logic Model

Start from one important problem and a specific evidence gap. State a central objective or hypothesis, then build a small set of aims that collectively address it.

For each aim, identify:

- Question and rationale.
- Design, input, or work package.
- Measurable deliverable and success criterion.
- Dependency on other aims.
- Main uncertainty and alternative route.
- How the result changes knowledge or the next decision.

A logic model can connect resources and activities to outputs, near-term outcomes, and longer-term impact. Mark assumptions and external dependencies. Avoid aims that are merely methods, overlap without purpose, or promise results rather than answerable questions.
