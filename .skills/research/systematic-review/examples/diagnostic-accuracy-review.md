# Example: Diagnostic Accuracy Review

**Illustrative methods outline; no test performance estimate is implied.**

## Question

In a defined population and setting, how accurately does an index test identify a target condition against an appropriate reference standard?

## Key protocol decisions

- Specify intended clinical role, threshold(s), population, setting, and reference standard.
- Include eligible designs and handle multiple thresholds and incomplete verification.
- Search for diagnostic studies, including registries or unpublished sources if justified.
- Extract true/false positive and negative counts or equivalent data, threshold, timing, and participant flow.
- Assess bias and applicability with a tool designed for diagnostic accuracy.
- Use a synthesis model that accounts for paired sensitivity/specificity and threshold variation when appropriate.

Avoid comparing isolated sensitivity values across different thresholds or settings as if directly interchangeable.
