# Paper Reading: Workflow Checklist

A practical run sheet for applying [Paper Reading](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Identify the research question
- [ ] Understand the context
- [ ] Identify the hypothesis
- [ ] Understand the study design
- [ ] Understand the data
- [ ] Understand the analysis
- [ ] Examine the results
- [ ] Evaluate the interpretation
- [ ] Identify limitations
- [ ] Extract the contribution

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
