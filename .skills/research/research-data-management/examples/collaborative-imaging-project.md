# Example: Collaborative Imaging Project

**Illustrative governance plan; local agreements and approvals govern actual use.**

A multi-site imaging team defines a common schema, site-specific responsible contacts, approved transfer routes, and a data-use agreement before transfer. Each site retains its local linkage key; the coordinating team receives coded data only when authorized.

The protocol documents scanner and acquisition metadata, quality-control procedures, software versions, and harmonization steps. A change log records schema and pipeline updates. Shared results are linked to the exact dataset and pipeline versions used.
