# Example: Open Computational Dataset

**Illustrative structure; all file names and records are examples.**

```text
project/
├── README.md
├── data/
│   ├── source/       # permitted, immutable inputs or retrieval instructions
│   └── derived/      # generated by versioned scripts
├── code/
├── metadata/
│   └── data-dictionary.csv
└── outputs/
```

The release records source, license, retrieval date, checksum, transformations, dependency versions, and analysis command. Confirm redistribution rights before including source data; otherwise provide a stable retrieval reference and instructions. Validate the documented workflow from a clean environment using a small, non-sensitive test.
