# Research Writing: Workflow Checklist

A practical run sheet for applying [Research Writing](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Understand the research
- [ ] Identify the research question
- [ ] Identify the research gap
- [ ] Identify the evidence
- [ ] Identify the analysis
- [ ] Build the argument
- [ ] Create the section outline
- [ ] Draft each section
- [ ] Add and verify citations
- [ ] Check claim strength

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
