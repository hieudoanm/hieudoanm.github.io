# Missing Data and Exclusions

Describe the amount, pattern, timing, and plausible causes of missingness for each important variable. Distinguish unavailable measurements from structural missingness and ineligible observations.

## Plan

- Define data validation and correction rules without overwriting source records.
- Specify prespecified exclusions and analysis populations.
- State primary missing-data method and assumptions.
- Consider sensitivity analyses for plausible departures from those assumptions.
- Report denominators and flow for every primary result.

Complete-case analysis can be biased and inefficient; use only with a rationale consistent with the design and missingness assumptions. Imputation requires a suitable model, auxiliary variables where justified, diagnostics, and transparent uncertainty propagation. Never invent missing values or imply that a method removes uncertainty.
