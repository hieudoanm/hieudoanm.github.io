# Example: Diagnostic Study Analysis Plan

**Illustrative plan; no diagnostic performance estimates are asserted.**

Define the target population, index test, reference standard, threshold, and intended use. Prespecify sensitivity, specificity, and uncertainty methods that account for paired classifications. Describe indeterminate results, missing reference standards, verification patterns, and subgroup thresholds.

Avoid selecting a cutoff on the same data and reporting its apparent performance as if independently validated. If thresholds are explored, label them exploratory and reserve validation data or an independent study for confirmation.
