# Literature Search Strategy

A literature review is only as good as the evidence it finds.

The purpose of a search strategy is to identify relevant literature
systematically and efficiently while minimizing avoidable selection bias.

## Start With the Research Question
Do not begin with random keyword searches.

First identify:

- Main concept.
- Population.
- Phenomenon.
- Intervention or exposure.
- Outcome.
- Method.
- Context.

Not every question needs all of these components.

## Search Terms
Include:

### Synonyms

Different researchers may use different terms for the same concept.

### Historical terminology

Older literature may use terminology that is no longer common.

### Abbreviations

Examples:

```text
functional magnetic resonance imaging
fMRI
```

### Alternative spellings

Consider regional spelling differences when relevant.

### Related constructs

Sometimes researchers describe the same phenomenon using a broader
or narrower term.

Do not add every vaguely related concept simply to increase the number
of results.

## Search Sources
Use appropriate scholarly databases and sources.

Examples include:

- PubMed.
- Google Scholar.
- Web of Science.
- Scopus.
- PsycINFO.
- IEEE Xplore.
- ACM Digital Library.
- arXiv.
- bioRxiv.
- medRxiv.

Choose sources based on the research field.

For neuroscience, relevant sources may include PubMed, Web of Science,
Scopus, PsycINFO, and specialist repositories.

## Search Iteratively
A strong search is usually iterative.

```text
Initial search
     ↓
Read relevant papers
     ↓
Discover terminology
     ↓
Refine search terms
     ↓
Search again
     ↓
Identify additional papers
```

Important papers often reveal terminology that was missing from the
initial search.

## Search Documentation
For systematic or reproducible reviews, record:

- Database.
- Search date.
- Search terms.
- Filters.
- Number of results.
- Screening criteria.
- Inclusion decisions.
- Exclusion reasons.

Example:

```text
Database: PubMed
Date: 2026-10-07

Query:
(speech OR language)
AND
("neural activity" OR "brain activity")
AND
(decoding OR prediction)

Results: N
Screened: N
Included: N
```

## Search Completeness
A search is not necessarily complete because it returned many papers.

Useful checks include:

- Were major papers found?
- Were landmark studies found?
- Did multiple databases produce similar core literature?
- Did citation chaining reveal important studies missed by keyword search?
- Did the search include alternative terminology?

## Search Bias
Be aware of:

- Publication bias.
- Database coverage bias.
- Language bias.
- Citation bias.
- Positive-result bias.
- Search-term bias.

A search strategy can systematically miss research even when it appears
comprehensive.

## Search Strategy Output
When documenting a literature search, report enough information that
another researcher can understand how the literature was identified.

At minimum:

```text
Research question
Scope
Databases
Search terms
Date range
Inclusion criteria
Exclusion criteria
Screening process
Citation chaining
Final evidence set
```

## Core Principle
> Search broadly enough to discover the evidence, then narrow systematically
> according to the research question.
