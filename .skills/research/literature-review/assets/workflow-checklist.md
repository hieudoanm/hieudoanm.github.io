# Literature Review: Workflow Checklist

A practical run sheet for applying [Literature Review](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Define the research question
- [ ] Define the scope and inclusion criteria
- [ ] Develop a search strategy
- [ ] Find relevant literature
- [ ] Screen studies for relevance
- [ ] Extract comparable evidence
- [ ] Assess methodological quality
- [ ] Group studies by themes, methods, populations, or findings
- [ ] Compare and contrast findings
- [ ] Identify areas of consensus

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
