# Example: Target-Trial Emulation

**Illustrative planning approach; no treatment recommendation or effect is implied.**

For observational data, write the hypothetical trial protocol first: eligibility, treatment strategies, assignment procedure, time zero, follow-up, outcome, causal contrast, and analysis. Then map each element to available data and identify where emulation differs.

Align eligibility, treatment classification, and follow-up to avoid immortal-time and selection biases. State exchangeability, consistency, positivity, and measurement assumptions. An emulation is not equivalent to randomization simply because it follows a trial-like template.
