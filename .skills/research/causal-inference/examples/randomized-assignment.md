# Example: Randomized Assignment

**Illustrative design sketch; no actual intervention effect is asserted.**

A trial asks whether offering a program changes a defined outcome at a fixed follow-up. Define the effect of assignment as the primary target, preserve allocation procedures, and report attrition and crossover. If estimating the effect of adherence, state the additional assumptions and method; a per-protocol comparison is not automatically causal.

Randomization supports baseline exchangeability for assignment when implemented correctly. It does not ensure adherence, equal measurement, absence of differential missingness, or generalization to other populations.
