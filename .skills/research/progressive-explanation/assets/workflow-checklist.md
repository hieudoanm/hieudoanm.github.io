# Progressive Explanation: Workflow Checklist

A practical run sheet for applying [Progressive Explanation](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Identify the concept
- [ ] Find the simplest correct mental model
- [ ] Identify essential terminology
- [ ] Choose concrete examples
- [ ] Explain the concept at all four levels
- [ ] Increase technical precision progressively
- [ ] Keep the underlying meaning consistent
- [ ] Add mathematics, assumptions, limitations, and edge cases only when useful

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
