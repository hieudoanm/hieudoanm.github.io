# Research Poster Skill: Workflow Checklist

A practical run sheet for applying [Research Poster Skill](../SKILL.md). Tailor each item to the current project and record evidence where the decision matters.

## Before starting

- [ ] Confirm the task is within this skill's scope.
- [ ] Check applicable versions, project conventions, and prerequisites.
- [ ] Define a measurable outcome and relevant constraints.

## Apply the skill

- [ ] Primary Output Requirements: <!DOCTYPE html>
- [ ] Primary Output Requirements: <html>
- [ ] Poster Rendering Requirements: Fixed dimensions
- [ ] Poster Rendering Requirements: Consistent margins
- [ ] Screenshot Requirement: The entire poster should fit within one defined canvas
- [ ] Screenshot Requirement: Avoid content that extends outside the poster
- [ ] Level 1 — Immediate: What is this research about?
- [ ] Level 1 — Immediate: What was the main question?
- [ ] Level 2 — Main evidence: How the study was conducted
- [ ] Level 2 — Main evidence: What was measured

## Complete the work

- [ ] Review tradeoffs and failure cases before adopting the result.
- [ ] Run the validation appropriate to the change.
- [ ] Record important assumptions and deviations for future maintainers.
